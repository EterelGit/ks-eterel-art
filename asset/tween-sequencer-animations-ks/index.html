Asset Overview

Tween Sequencer Animations KS is an Inspector-based animation authoring tool for standard Unity components. An `AnimationSequencerController` stores a list of steps. Steps animate targets, wait, call events, set properties, or include another controller's sequence. Animations update component properties through Unity APIs. The package's C# code handles timing, interpolation, repeats and sequence playback during runtime and editor preview. This is not Unity's built-in Animator/Animation implementation or a native engine module; Animator and Animation can be started through dedicated playback steps. **The asset does not use DOTween, does not depend on DOTween or DOTween Pro, and is not based on the DOTween engine. It is a fully independent implementation with its own tween runtime, sequencing and preview system.** There is no external tween package to install. All runtime types live in `TweenSequencerAnimationsKS` and `TweenSequencerAnimationsKS.Tweening`. The `DO...` shortcut names and legacy `MovedFrom` strings are local APIs and serialization compatibility metadata. They do not reference `DG.Tweening` or require a DOTween assembly. When another tween library is installed, import only the namespace needed by your code to avoid similarly named extension methods.

Technical Specifications

Independent C# tween engine — no DOTween or external tween engine required. 27 actions + 12 utility & playback steps for Transform, RectTransform, UI, TextMeshPro and Renderers. Inspector-based authoring with step reordering, copy, paste and duplication. Sequence composition with sequential and parallel steps, nested sequences, delays and callbacks. Animation controls including built-in easing, custom AnimationCurves, To/From/Relative modes and axis constraints. Playback options including Restart/Yoyo loops, loop delays, adjustable speed, reverse playback and seeking. Edit-mode preview with progress scrubbing and automatic restoration of captured values when preview stops. Code API for playback control, events, coroutines and runtime target replacement. Unity integration with Animator, legacy Animation and Particle System playback steps. Render pipeline independent runtime — materials and shaders must support your project's render pipeline. Installation: Unity Package Manager. Example scene and user manual included.
