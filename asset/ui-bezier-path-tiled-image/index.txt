13:T48b,**UI Bezier Path Tiled Image** lets you draw curved, textured paths directly on a Unity Canvas. Use it for map routes, skill tree connections, progress indicators, timelines, and animated cables or energy lines.

**Shape paths in the Scene view**

Move Transform control points to define the route. Adjust corner roundness and width at individual points to create tight bends, smooth turns or tapered sections. The component generates the UI mesh automatically and creates three starter points when the point list is empty. Add and reorder points in the Inspector, or close the path into a loop.

**Repeat textures along the path**

Assign a texture and use Tile Length to control how often it repeats. The texture follows the path by distance, so you can change the shape while keeping the tiling consistent. Apply a color gradient along the path for additional control over color and opacity.

**Animate the path from either end**

Use Fill Right and Fill Left to reveal a route from its start, its end, or both ends. Move control points at runtime to update connections between moving UI elements. For fixed paths, enable Static Points to skip movement checks.14:T4fc,- **Version** — 1.3.8.
- **Requirements** — Unity UI (uGUI), a Canvas, and at least two valid Transform control points.
- **Component** — `UIBezierTiledImage`, based on `MaskableGraphic`. Generates geometry with `VertexHelper`.
- **Path controls** — Ordered Transform points, per-point Roundness and Width Multiplier, adjustable Roundness Segments, and optional closed loops.
- **Texture mapping** — UVs advance by path distance. Tile Length controls repeat spacing. Use Repeat or Mirror wrap mode for tiling. With no texture assigned, the component uses Unity’s white UI texture.
- **Color** — A gradient controls vertex color and alpha along the path.
- **Fill animation** — Fill Right and Fill Left each range from 0 to 1. If their sum exceeds 1, the values are normalized to fit the full path.
- **Runtime updates** — Moving control points rebuild the mesh when Static Points is disabled.
- **Editor tools** — Scene view gizmos, a reorderable point list, and a texture wrap mode warning.
- **Geometry note** — In 1.3.8, Width and the per-point Width Multiplier control strip thickness. The serialized Height field does not independently affect the geometry.
