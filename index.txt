Steps animate targets, wait, call events, set properties, or include another controller's sequence. Animations update component properties through Unity APIs. The package's C# code handles timing, interpolation, repeats and sequence playback during runtime and editor preview. This is not Unity's built-in Animator/Animation implementation or a native engine module; Animator and Animation can be started through dedicated playback steps.

**The asset does not use DOTween, does not depend on DOTween or DOTween Pro, and is not based on the DOTween engine. It is a fully independent implementation with its own tween runtime, sequencing and preview system.** There is no external tween package to install.

All runtime types live in `TweenSequencerAnimationsKS` and `TweenSequencerAnimationsKS.Tweening`. The `DO...` shortcut names and legacy `MovedFrom` strings are local APIs and serialization compatibility metadata. They do not reference `DG.Tweening` or require a DOTween assembly.
